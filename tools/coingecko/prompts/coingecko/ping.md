# CoinGecko: ping

Run the legacy ping operation. See the prompt and input schema for its exact contract.

Legacy tool context: Universal cryptocurrency crypto price and market tool for CoinGecko. Support for both free Demo API key (api.coingecko.com) and Pro API key (pro-api.coingecko.com).

## Inputs

- `pro` (optional): Set to true to use the Pro API domain (pro-api.coingecko.com). Default is false.

The operation is selected by IronClaw as `coingecko.ping`. Do not send the private `action` selector.
