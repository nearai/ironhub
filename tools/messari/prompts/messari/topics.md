# Messari: topics

Run the legacy topics operation. See the prompt and input schema for its exact contract.

Legacy tool context: Messari crypto research and market data tool for Ironclaw. Access prices, market metrics, news, token unlocks, fundraising rounds, DeFi protocols, network stats, and Messari AI synthesis.

## Inputs

- `limit` (optional): Max topics to return (default 20).

The operation is selected by IronClaw as `messari.topics`. Do not send the private `action` selector.
